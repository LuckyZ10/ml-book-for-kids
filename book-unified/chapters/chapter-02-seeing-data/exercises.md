## 进阶练习

### 练习6：TF-IDF手工计算（理解算法本质）

假设有一个极简的文档集合：

| 文档ID | 内容 |
|--------|------|
| D1 | "猫 喜欢 鱼" |
| D2 | "狗 喜欢 骨头" |
| D3 | "猫 喜欢 牛奶" |

**任务**：
1. 统计词频（TF）：每个词在每个文档中出现几次？
2. 计算逆文档频率（IDF）：每个词在几篇文档中出现？
3. 手工计算每个词在每个文档中的TF-IDF值（使用公式：TF-IDF = TF × log(N/DF)，其中N=3）
4. 用TF-IDF向量表示每篇文档，计算D1和D3的余弦相似度
5. 思考：为什么"喜欢"的TF-IDF值会比较低？这符合直觉吗？

### 练习7：数据标准化对比（实验设计）

假设有两组数据：
- 房屋面积（平方米）：[50, 80, 120, 200, 500]
- 房龄（年）：[1, 5, 10, 20, 50]

**任务**：
1. 对两组数据分别进行Min-Max标准化（缩放到[0, 1]）
2. 对两组数据分别进行Z-score标准化（均值为0，标准差为1）
3. 比较两种标准化后的结果：
   - 哪种方法对异常值更敏感？
   - 如果房屋面积中出现了一个错误值5000（实际应为500），哪种标准化方法受影响更大？
4. 在什么情况下你会选择Min-Max？什么情况下选择Z-score？

### 练习8：特征编码实战（类别数据处理）

你正在处理一个水果数据集，其中"颜色"特征有以下取值：

```
[红, 绿, 黄, 红, 橙, 绿, 红, 黄, 橙, 绿]
```

**任务**：
1. 用标签编码（Label Encoding）将其转换为数值
2. 用独热编码（One-Hot Encoding）将其转换为向量
3. 分析两种编码的优缺点：
   - 标签编码会产生什么潜在问题？（提示：数值大小意味着什么？）
   - 独热编码的维度是多少？如果有100种不同颜色呢？
4. 设计一个新的编码方法，能保留颜色之间的"相似性"信息（例如：红色和橙色比红色和绿色更"接近"）

### 练习9：异常值检测（编程挑战）

给定以下考试成绩数据：

```python
scores = [78, 82, 85, 88, 90, 92, 95, 96, 98, 100, 35, 102]
```

**任务**：
1. 用"3σ原则"（超过3个标准差视为异常）找出异常值
2. 用"箱线图法"（IQR = Q3 - Q1，超出[Q1-1.5×IQR, Q3+1.5×IQR]视为异常）找出异常值
3. 比较两种方法的结果：哪种方法更保守？哪种更激进？
4. `102`分是一个有效成绩还是错误数据？`35`分呢？你如何区分"异常值"和"错误数据"？
5. 写一个Python函数，实现上述两种异常值检测方法
