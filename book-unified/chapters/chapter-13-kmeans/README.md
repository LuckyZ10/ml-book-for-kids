# 第十三章：K-Means聚类——物以类聚

## 章前小语

> "相似的人会走到一起。"

你有没有注意过这个现象：学校食堂里，爱打游戏的同学会坐在一起；图书馆里，认真读书的同学会聚成一堆；操场上，踢足球的和打篮球的自然分成不同的区域。

这不是巧合，而是**物以类聚，人以群分**。

在机器学习的世界里，有一种算法专门做这件事——**自动把相似的东西放在一起**。它不需要事先知道有哪些类别，只需要告诉你"这里应该有3个群"或者"分成5组"，它就能把一堆混乱的数据整理得井井有条。

这就是**K-Means聚类算法**，机器学习中最简单、最优雅、也最强大的无监督学习算法之一。

## 开篇故事：贝尔实验室的深夜与25年的秘密

### 1957年的新泽西：一个被锁在保险箱里的发现

1957年的秋天，新泽西州默里山的贝尔实验室总部，一位年轻的数学家正盯着面前一堆密密麻麻的信号数据发愁。

他的名字叫**斯图尔特·劳埃德（Stuart Lloyd）**。当时，贝尔实验室是全球最前沿的科研机构，这里诞生了晶体管、激光、信息论，以及无数改变世界的技术。劳埃德的任务听起来很普通：如何把模拟语音信号数字化，让电话公司能用更少的带宽传输更多的通话？

当时的主流方案是脉冲编码调制（PCM）——把声音切成小段，每段用一个数字代表。但问题是：如果用同样的精度表示所有信号，有些不重要的地方浪费了太多比特，而重要的地方比特又不够。

劳埃德盯着信号图看了整整三天。突然，一个想法像闪电一样击中了他：**为什么不把信号空间分成几个区域，每个区域用一个"代表点"来概括？** 就像一群选民选出一个议员代表他们的利益一样，让几个"中心点"代表所有数据。

他迅速在纸上画出了算法的草图：
1. 随机选几个代表点
2. 把每个信号点分配给最近的代表
3. 重新计算每个组的中心
4. 重复直到稳定

这个思路简单得令人难以置信，但效果出奇地好。劳埃德在内部技术报告中记录了这个发现，兴奋地预测这将"彻底改变信号量化领域"。

然而，命运弄人。贝尔实验室当时正与美国军方合作一个机密项目，劳埃德的算法被判定为"具有潜在军事价值"。他的论文被盖上了"机密"印章，锁进了保险箱。除了少数几个同事，没人知道这个发现的存在。

**25年过去了。**

### 1982年：迟来的发表与命名之争

1982年，随着项目解密，劳埃德终于在他的论文上看到了自己的名字。这篇题为《最小二乘量化在PCM中的应用》的论文发表在《IEEE信息论汇刊》上，立即引起了统计学界的轰动。

但此时，学术界已经"重新发现"这个算法两次了：
- **1965年**，爱德华·福吉（Edward Forgy）独立发表了相同的算法，称为"Forgy算法"
- **1967年**，詹姆斯·麦克奎因（James MacQueen）在第五届伯克利统计学年会上正式命名它为"K-Means"

于是，这个算法有了三个"父亲"：
- **劳埃德**：最早的发明者（1957年）
- **福吉**：最早的公开发表者（1965年）
- **麦克奎因**：命名者（1967年）

今天，学术界通常称它为"Lloyd-Forgy-MacQueen算法"，但"K-Means"这个名字已经太顺口了，谁也改不了。

劳埃德本人对此很豁达。他在一次采访中笑着说："我不在乎它叫什么。我在乎的是，70年后人们还在用它。"他的愿望实现了——今天的数据科学家、机器学习工程师、生物信息学家，每天都在运行这个1957年诞生的算法。

### 2007年：K-Means++的聪明种子

半个世纪后，康奈尔大学的两位研究生坐在咖啡厅里，讨论一个困扰了所有人的问题：

"K-Means什么都好，就是对初始值太敏感了。"大卫·亚瑟（David Arthur）说。

"是啊，"谢尔盖·瓦西里维茨基（Sergei Vassilvitskii）附和，"如果初始点选得不好，整个算法就废了。"

亚瑟盯着咖啡杯里的奶泡图案，突然灵光一闪："如果我们让初始点互相远离呢？"

这个简单的想法，催生了一个优雅的解决方案：
1. 随机选第一个中心
2. 计算每个点到最近中心的距离
3. 以**与距离平方成正比的概率**选择下一个中心
4. 重复直到选够K个

"距离越大的点，被选中的概率越高。"亚瑟在白板上画出概率分布，"这样中心点会自然分散开来，不会扎堆。"

2007年，这篇论文发表在ACM-SIAM离散算法研讨会上，立即成为引用量最高的聚类论文之一。他们证明了：K-Means++的期望损失不超过最优值的 $O(\log K)$ 倍。

### 从电话信号到基因分析：K-Means的旅程

K-Means的故事告诉我们一个深刻的道理：**最简单的想法，往往最有生命力。**

劳埃德发明的初衷是解决电话信号压缩问题。70年后，这个算法被用来：
- 分析癌症患者的基因数据，找出不同亚型
- 为电商平台的千万用户分群，实现精准营销
- 压缩高清视频的颜色，节省带宽
- 分析天文数据，发现星系团

一个从电话信号处理中诞生的算法，最终成为了数据科学最通用的工具之一。这不是偶然——它的简洁性、可解释性和计算效率，让它经受住了时间的考验。

> "简单是终极的复杂。" —— 达·芬奇

现在，让我们走进这个历经70年仍然生机勃勃的算法。

## 费曼四步检验框：什么是聚类？

### 📝 费曼四步学习法

**第一步：选择一个概念**
聚类（Clustering）—— 把相似的东西自动分到一起

**第二步：假装教给一个孩子**

想象你是一个幼儿园老师，面前有100个不同颜色的积木：红色的、蓝色的、绿色的、黄色的，混在一起。

你对小朋友们说："把这些积木分类放好！"

小朋友们会怎么做？
- 小红把所有的红色积木放在一起
- 小明把所有的蓝色积木放在一起
- 小花把所有的圆形积木放在一起（她按形状分！）
- 小强把所有的大的积木放在一起（他按大小分！）

不管按什么标准，小朋友们都在做**聚类**：找到"相似"的东西，把它们放到一起。

聚类算法做的完全一样的事！只不过它不是看颜色、形状或大小，而是看**数字特征**。

**第三步：发现知识漏洞，回到原材料**

等等，"相似"是什么意思？
- 两个积木都是红色 → 相似
- 两个积木都是圆形 → 相似  
- 两个积木大小一样 → 相似

在数学中，"相似" = "距离近"。如果两个东西在数字空间里离得近，我们就认为它们相似。

**核心发现**：聚类 = 把距离近的点分到一起！

**第四步：简化和类比**

**类比：整理书包**

想象你的书包里乱糟糟的：课本、铅笔、橡皮、零食、玩具全混在一起。

聚类算法就像你整理书包的过程：
1. 你先随便选几个"整理中心"（比如"放课本的地方"、"放文具的地方"）
2. 把每样东西放到最近的中心
3. 重新看看每个中心的位置是否合理
4. 重复直到整理满意

最后，你的书包变得井井有条：课本一堆、文具一堆、零食一堆。

这就是聚类的本质：**从无序中发现秩序**。

## 13.1 什么是聚类？

### 13.1.1 有监督 vs 无监督

还记得我们之前学过的分类算法吗？比如朴素贝叶斯、决策树、支持向量机？它们都有一个共同点：**需要提前知道答案**。

- 训练决策树时，你需要告诉它"这是苹果，那是橙子"
- 训练朴素贝叶斯时，你需要标记好垃圾邮件和非垃圾邮件

这种学习方式叫**有监督学习**(Supervised Learning)——就像有个老师在旁边告诉你对错。

但现实生活中，很多数据是没有标签的：
- 一家电商公司有100万用户，如何把他们分成不同的群体？
- 一个天文台观测到1000颗星星，如何发现其中的规律？
- 医生收集了1000个病人的基因数据，如何找出患同种疾病的人群？
- 博物馆有10万件藏品，如何自动整理分类？
- 社交媒体上有百万条帖子，如何发现热门话题？

这时候，**无监督学习**(Unsupervised Learning)就派上用场了。聚类(Clustering)就是无监督学习的主力军：它不需要你告诉它"正确答案",它会自己发现数据中的结构。

### 13.1.2 聚类的直觉：从生活到数学

想象你是一堆水果，有苹果、橙子、香蕉，混在一起。我要你把它们分开。

最简单的方法是什么？

**看颜色**：红色的放一堆，橙色的放一堆，黄色的放一堆。

**看形状**：圆的放一堆，长的放一堆。

**看大小**：大的放一堆，小的放一堆。

聚类算法做的就是这样的事——找到数据中的"相似之处"，把相似的放在一起。

**关键问题**：什么叫"相似"？

在数学中，"相似" = "距离近"。如果两个东西在数字空间里离得近，我们就认为它们相似。

比如：
- 客户A：[年龄=25, 收入=5000, 购买频次=10]
- 客户B：[年龄=27, 收入=5500, 购买频次=12]
- 客户C：[年龄=60, 收入=20000, 购买频次=2]

A和B的距离很小 → 相似 → 应该在一组
A和C的距离很大 → 不相似 → 应该分开

### 13.1.3 聚类的目标函数

聚类的数学目标可以概括为：

**让组内距离小，组间距离大。**

用公式表示：
- **紧凑性**（Compactness）：同一簇内的样本尽可能接近
- **分离性**（Separation）：不同簇的样本尽可能远离

好的聚类算法会同时优化这两个目标。

### 13.1.4 聚类的应用场景全景

聚类算法几乎无处不在：

| 领域 | 应用 | 算法 |
|:---|:---|:---|
| 商业 | 客户分群 | K-Means |
| 医疗 | 疾病亚型发现 | 层次聚类 |
| 互联网 | 新闻分类、话题发现 | K-Means + LDA |
| 生物 | 基因表达分析 | K-Means / 谱聚类 |
| 图像 | 颜色量化、分割 | K-Means |
| 天文 | 星系分类 | DBSCAN |
| 安全 | 异常检测、入侵检测 | K-Means + 阈值 |
| 推荐 | 用户兴趣分群 | K-Means + 协同过滤 |
| 工业 | 设备故障模式识别 | 层次聚类 |
| 城市规划 | 区域功能划分 | K-Means + GIS |

## 13.2 K-Means：划时代的算法

### 13.2.1 历史的轨迹

K-Means算法有着一段有趣的历史。

**1967年**，贝尔实验室的数学家**James MacQueen**首次提出了"K-Means"这个名字和算法框架。但在那之前，类似的思路已经在不同领域出现过：
- 1957年，物理学家Hugo Steinhaus在研究力学问题时提出了类似的思想
- 1965年，Edward Forgy独立发表了相同的算法（也叫Lloyd-Forgy算法）

**1982年**，贝尔实验室的**Stuart Lloyd**正式发表了现在最常用的版本——**Lloyd算法**，虽然他的工作早在1957年就完成了，但因为是军事项目直到25年后才解密发表。

所以，严格来说，这个算法应该叫**Lloyd-Forgy-MacQueen算法**，但"K-Means"这个名字太顺口了，就这么叫了下来。

### 13.2.2 算法的核心思想：两个步骤改变世界

K-Means的名字很直白：
- **K** = 你想分成几组（K个组）
- **Means** = 用平均值来找到组的中心

算法只有两步，简单到不可思议：

**第一步：分配**(Assignment)
把每个点分配到离它最近的"中心点"

**第二步：更新**(Update)
重新计算每个组的中心点（就是组内所有点的平均值）

然后……重复这两步，直到中心点不再移动。

就这两步！没有复杂的数学，没有梯度下降，就是"分配-更新"循环。

### 13.2.3 直观的例子：教室里的分小组

想象你要在教室里把30个同学分成3组（K=3）。

**初始**：你随机选了3个同学作为组长，站在教室的3个位置。

**第一轮分配**：每个同学都走向离自己最近的组长，形成3个圈。

**第一轮更新**：每个圈重新选中心——大家往中间挤一挤，找到圈的几何中心。

**第二轮分配**：根据新的中心位置，有些同学发现自己离另一个圈的中心更近，就换过去了。

**第二轮更新**：新的圈又有了新的中心……

就这样，几轮之后，大家就稳定在3个圈里不再移动了。这3个圈，就是算法找到的"聚类"。

### 13.2.4 生活化比喻：披萨店的配送区域

想象你开了一家披萨店，要决定**配送区域**。

你有3辆配送车（K=3），要覆盖整个城市。

**K-Means告诉你怎么做**：
1. 先随机放3个配送站（初始中心）
2. 每个客户自动分配给最近的配送站（分配）
3. 看看每个配送站的客户都住在哪里，把配送站搬到这些客户的"中间位置"（更新）
4. 有些客户发现自己离另一个配送站更近了，就换过去
5. 重复直到每个配送站的覆盖范围稳定

最后，你得到了3个完美的配送区域，每个区域的客户到配送站的平均距离最短！

这就是K-Means的智慧：**让每个"中心"服务离它最近的"客户"，同时不断优化中心位置。**

### 13.2.5 另一个比喻：整理衣柜

想象你的衣柜乱糟糟的，T恤、裤子、外套、袜子全混在一起。

你想把它们分成4类（K=4）。

**K-Means过程**：
1. 你随机选了4件衣服作为"样板"（初始中心）
2. 每件衣服都归到和样板最像的那一类（分配）
3. 重新看每一类的"平均特征"，更新样板（更新）
4. 有些衣服发现自己和另一个样板更像，就换过去
5. 重复直到分类稳定

最后你可能发现：
- 一类是"短袖T恤"（棉质、轻薄、休闲）
- 一类是"正装衬衫"（棉质、挺括、商务）
- 一类是"牛仔裤"（牛仔布、厚实、休闲）
- 一类是"运动服"（速干、弹性、运动）

注意：**K-Means不知道这些名字**！它只是根据特征把相似的衣服放在一起，名字是你后来赋予的。这就是无监督学习的魅力——它发现结构，但不给结构命名。

## 13.3 数学原理

### 13.3.1 损失函数：为什么要最小化距离平方？

K-Means要最小化的损失函数非常优雅：

$$J = \sum_{i=1}^{K} \sum_{x \in C_i} \|x - \mu_i\|^2$$

什么意思？
- $C_i$ 是第$i$个聚类中的所有点
- $\mu_i$ 是第$i$个聚类的中心（所有点的平均值）
- $\|x - \mu_i\|^2$ 是点$x$到中心的距离平方
- 我们要最小化所有点到它们所属聚类中心的距离平方和

这叫做**惯性**(Inertia)或**簇内平方和**(Within-Cluster Sum of Squares, WCSS)。

**直觉理解**：想象你是一位老师，要把学生分成几个小组。你希望每个小组的学生都"志趣相投"——也就是他们之间的"距离"很小。WCSS就是衡量"不志趣相投程度"的指标：WCSS越小，说明每个组内的成员越相似。

**为什么用距离平方而不是距离本身？**

这是一个经典问题。答案是：
1. **数学上更优雅**：平方让损失函数可导，方便优化
2. **对大偏差更敏感**：距离平方会"惩罚"远离中心的点，让它们更愿意回到群体
3. **几何意义明确**：距离平方和等于惯性矩，有清晰的物理意义

### 13.3.2 为什么两步迭代有效？EM算法的雏形

Lloyd算法的两步看似简单，其实有深刻的数学原理。它其实是**EM算法**（期望最大化算法）的一个特例。

**固定中心，优化分配（E步骤）**：
给定中心点$\mu_1, ..., \mu_K$，对每个点$x$，把它分配到最近的中心：
$$c(x) = \arg\min_i \|x - \mu_i\|^2$$
这一定是最优的，因为我们要最小化距离平方和。

**固定分配，优化中心（M步骤）**：
给定分配，每个聚类的最优中心是什么？
对$\mu_i$求导并令导数为0：
$$\frac{\partial J}{\partial \mu_i} = -2\sum_{x \in C_i}(x - \mu_i) = 0$$
解得：
$$\mu_i = \frac{1}{|C_i|}\sum_{x \in C_i} x$$
就是**平均值**！这就是为什么叫"K-Means"。

所以，两步交替进行，每次都能降低损失函数，最终收敛到局部最优。

### 13.3.3 收敛性保证：为什么K-Means一定会停下来？

K-Means有两个重要的收敛性质：

1. **单调性**：每一轮迭代，损失函数$J$都不会增加（只会减小或不变）
   - E步骤：固定中心，最优分配 → $J$不增
   - M步骤：固定分配，最优中心 → $J$不增
   
2. **有限性**：因为分配方式是有限的（$K^N$种可能），算法一定会在有限步内收敛

**但要注意**：它收敛的是**局部最优**，不是全局最优。就像爬山，你可能只爬到附近的小山顶，而不知道远处还有更高的山峰。这就是为什么初始化很重要——好的起点能让你爬到更高的山顶。

### 13.3.4 几何直觉：Voronoi图

K-Means的分配步骤有一个美丽的几何解释：**Voronoi图**。

想象平面上有K个中心点。Voronoi图把平面分成K个区域，每个区域包含"离某个中心最近的所有点"。

K-Means的每一次分配，就是在画一张Voronoi图！然后更新步骤移动中心点，Voronoi图也随之改变。

这个视角告诉我们：K-Means找到的聚类边界，总是直线（在高维空间是超平面），因为Voronoi图的边界是垂直平分线。

这也是为什么K-Means假设簇是**凸的、球形的**——它的几何本质决定了这一点。

## 13.4 初始化问题与K-Means++

### 13.4.1 初始化的陷阱

K-Means的一个大问题是：**随机初始化**。

想象一下：你的3个初始组长刚好都站在教室的左边，会发生什么？

- 左边的同学分成3组（其实应该是一组）
- 右边的同学被强行分配到左边某个组
- 最终结果是错的！

这就是**局部最优陷阱**。K-Means对初始中心点非常敏感，不同的初始化可能得到完全不同的结果。

### 13.4.2 K-Means++：聪明的初始化

**2007年**，康奈尔大学的**David Arthur**和**Sergei Vassilvitskii**提出了**K-Means++**算法，解决了初始化问题。

核心思想：**让初始中心点彼此远离**。

算法步骤：
1. 随机选第一个中心点
2. 对每个数据点$x$，计算它到最近已选中心的距离$D(x)$
3. 以概率$\frac{D(x)^2}{\sum D(x)^2}$选择下一个中心点（距离越大的点被选中的概率越大）
4. 重复直到选够$K$个中心

直观理解：**已经被覆盖的区域不太可能再选中心，中心点会自然分散开来**。

### 13.4.3 理论保证：为什么K-Means++有效？

Arthur和Vassilvitskii证明了惊人的结果：

**定理**：K-Means++初始化后，损失函数的期望值不超过最优值的$8(\ln K + 2)$倍。

这意味着：即使后面只用标准的Lloyd算法，K-Means++也能给出接近最优的结果！

**证明直觉**：
- 如果初始中心彼此远离，每个中心覆盖的区域不会太大
- 覆盖区域不大 → 簇内距离平方和不大
- 数学上可以严格证明，期望损失有$O(\log K)$的上界

**实践意义**：
- K-Means++几乎总是比随机初始化好很多
- 计算成本增加很小（只多了初始化步骤）
- 现在sklearn等库已经默认使用K-Means++

### 13.4.4 K-Means++的概率直觉

为什么用**距离平方**作为概率权重？

**直觉**：
- 一个点离所有已选中心都很远 → 它很可能是"新簇"的代表 → 应该被选为中心
- 距离的平方放大了这个效应，让远离的点更有优势
- 这与物理中的"势能"概念类似：距离越远，势能越大

**数学原因**：
- 期望损失与距离的平方成正比
- 用距离平方作为采样概率，恰好平衡了"探索"和"利用"

### 13.4.5 初始化方法的全面比较

| 方法 | 时间复杂度 | 近似比 | 稳定性 | 推荐度 |
|:---|:---:|:---:|:---:|:---:|
| 随机 | $O(K)$ | 无保证 | 差 | ⭐ |
| K-Means++ | $O(nK)$ | $O(\log K)$ | 好 | ⭐⭐⭐⭐⭐ |
| 最远点采样 | $O(nK)$ | 无保证 | 中 | ⭐⭐⭐ |
| PCA投影+量化 | $O(nd^2)$ | 无保证 | 好 | ⭐⭐⭐⭐ |
| 多次随机选最优 | $O(nK \cdot n_{init})$ | 经验好 | 好 | ⭐⭐⭐⭐ |

**实践建议**：除非有特殊需求，始终使用K-Means++。

## 13.5 如何选择K？

### 13.5.1 肘部法则

K-Means需要你事先指定K（聚类数量）。但怎么选K呢？

最常用的方法是**肘部法则**(Elbow Method)：

1. 尝试不同的K值（比如1到10）
2. 对每个K运行K-Means，记录损失函数值$J(K)$
3. 画出$J(K)$随K变化的曲线
4. 找到曲线的"肘部"——K增加时$J$下降最快的点

为什么叫肘部？因为曲线通常像人的手臂，有个明显的"拐弯"处。

### 13.5.2 轮廓系数

另一个评估指标是**轮廓系数**(Silhouette Coefficient)：

$$s = \frac{b - a}{\max(a, b)}$$

其中：
- $a$ 是一个点到同簇其他点的平均距离（簇内紧密度）
- $b$ 是一个点到最近其他簇的平均距离（簇间分离度）

轮廓系数的范围是$[-1, 1]$：
- 接近1：聚类效果好
- 接近0：点在边界上
- 接近-1：可能分错了

### 13.5.3 其他方法

- **轮廓分数曲线**：选择平均轮廓系数最大的K
- **Davies-Bouldin指数**：越小越好
- **Calinski-Harabasz指数**：越大越好
- **信息准则**：AIC、BIC（基于概率模型）

### 13.5.4 可视化技巧：让选择K变得直观

**方法一：同时画多个指标**

在同一个图上画出肘部法则、轮廓系数、Davies-Bouldin指数，综合判断最佳K值。单一指标可能误导，多指标交叉验证更可靠。

**方法二：可视化聚类结果**

对不同的K值，画出聚类结果的散点图（用t-SNE降到2维）。直观对比：
- K=2：两个大簇，可能太粗
- K=3：看起来自然
- K=5：有些簇只有几个点，过拟合了

**方法三：稳定性分析**

对同一个K，多次运行K-Means（不同的随机种子），看看聚类结果是否稳定：
- 如果每次结果都很像 → K可能合适
- 如果每次结果差异很大 → K可能不合适，或数据结构本身模糊

**方法四：业务验证**

 ultimately，**K的值不是纯数学问题，而是业务问题**。问你：
- 营销部门能处理几个客户群体？
- 产品线有几个定位？
- 生物学上已知的亚型有几个？

数学指标给建议，业务需求做决定。

### 13.5.5 选K的哲学：没有完美答案

重要提醒：**不存在"最佳K"的唯一正确答案**。

K-Means的K是一个**超参数**，就像学习率、正则化强度一样，需要根据场景调整。

**实用建议**：
1. 先用肘部法则缩小范围（比如K在3-7之间）
2. 对每个候选K，做稳定性分析和业务解读
3. 选择"既让数学指标满意，又让业务人员理解"的K
4. 记录决策过程，方便后续复盘

## 13.6 K-Means的优缺点：全面了解你的工具

### 13.6.1 优点

1. **简单高效**：时间复杂度$O(n \cdot K \cdot d \cdot i)$，其中$n$是样本数，$K$是聚类数，$d$是维度，$i$是迭代次数。通常收敛很快（\< 100轮）。

2. **可扩展**：可以处理大规模数据，尤其是Mini-Batch K-Means变体，能处理百万级样本。

3. **结果可解释**：每个聚类有明确的中心点，容易理解。你可以说"这个簇的代表特征是..."

4. **广泛应用**：图像压缩、客户分群、文档聚类、基因分析……无处不在。

5. **内存友好**：只需要存储K个中心点，预测新样本时非常高效。

### 13.6.2 缺点

1. **需要指定K**：不知道K的时候很头疼。但好消息是：肘部法则、轮廓系数等工具可以帮你。

2. **对初始值敏感**：虽然K-Means++解决了大部分问题，但仍有随机性。建议多次运行取平均。

3. **假设球形簇**：K-Means假设簇是球形的（基于距离），对非凸形状效果差。解决方法：用DBSCAN或谱聚类。

4. **对异常值敏感**：一个远离的点会严重影响中心位置。解决方法：预处理删除异常值，或用K-Medoids。

5. **等方差假设**：假设各个方向的方差相同，对椭球形数据效果不好。解决方法：先标准化数据。

6. **无法处理空簇**：如果某个簇没有样本，需要特殊处理（重新初始化或删除该簇）。

### 13.6.3 何时用K-Means？何时不用？

**用K-Means当**：
- 数据量很大（n > 1000）
- 簇大致是球形
- 需要快速结果
- 需要可解释的中心点
- 噪音较少

**不用K-Means当**：
- 簇形状复杂（环形、S形、月牙形）
- 数据噪声严重
- 需要自动确定聚类数
- 数据量极小（n \< 50，此时层次聚类更好）
- 需要"软聚类"（概率分配）

### 13.6.4 K-Means vs 其他聚类算法：选择指南

| 场景 | 推荐算法 | 理由 |
|:---|:---|:---|
| 大数据、球形簇 | **K-Means** | 快、可扩展、效果好 |
| 大数据、噪声多 | **DBSCAN** | 自动识别噪声、无需指定K |
| 小数据、需层次 | **层次聚类** | 提供树状图、无需指定K |
| 复杂形状 | **谱聚类** | 基于图论、任意形状 |
| 高维数据 | **先PCA再K-Means** | 降维后距离更有意义 |
| 需要软分配 | **Fuzzy C-Means** | 概率隶属度 |
| 异常值多 | **K-Medoids** | 对异常值鲁棒 |

### 13.6.5 K-Means的最佳实践清单

在实战中使用K-Means时，按这个清单检查：

- [ ] **标准化数据**：用StandardScaler或MinMaxScaler
- [ ] **处理缺失值**：删除或填充
- [ ] **处理离群点**：IQR法则或Z-score过滤
- [ ] **降维（高维时）**：先用PCA降到10-50维
- [ ] **使用K-Means++初始化**：sklearn默认已启用
- [ ] **设置random_state**：保证可复现
- [ ] **多次运行**：n_init=10或更高
- [ ] **选择K**：肘部法则 + 轮廓系数 + 业务理解
- [ ] **可视化**：用t-SNE降到2维，检查聚类合理性
- [ ] **解释结果**：给每个簇命名，描述特征
- [ ] **验证稳定性**：多次运行，看结果是否一致

## 13.8 K-Means的变体家族

K-Means有很多"兄弟姐妹"，针对不同的场景做了优化。

### 13.8.1 Mini-Batch K-Means：大数据的加速器

**问题**：标准K-Means每次迭代都要看所有数据。当n=1000万时，太慢了！

**解决方案**：每次只看一小批数据（mini-batch）。

**算法**：
1. 随机初始化中心
2. 重复：
   - 随机选batch_size个样本
   - 对这些样本做分配和更新
   - 用增量方式更新中心（而非重新计算）

**优点**：速度快10-100倍，内存占用小
**缺点**：结果略差于标准K-Means，但通常可接受

**适用**：n > 10万的大数据集

### 13.8.2 K-Medoids：对异常值更鲁棒

**问题**：K-Means用"平均值"作为中心，一个异常值就能把中心拉偏。

**解决方案**：用"中位数点"（medoid）代替"平均值"。

Medoid = 簇内到其他点距离之和最小的那个点（必须是真实数据点）。

**优点**：对异常值不敏感
**缺点**：计算更慢（$O(n^2)$）

**适用**：数据有噪声、异常值多的场景

### 13.8.3 Fuzzy C-Means：软聚类

**问题**：K-Means是"硬分配"——每个点只能属于一个簇。但现实中，很多点是"中间地带"。

**解决方案**：让每个点以概率属于多个簇。

**核心思想**：
- 每个点有一个"隶属度向量"$u = [u_1, u_2, ..., u_K]$
- $u_i$表示属于第i个簇的程度（0到1之间）
- 所有隶属度之和为1

**比喻**：一个学生可能同时属于"数学兴趣组"（隶属度0.7）和"物理兴趣组"（隶属度0.3）。

**适用**：边界模糊、需要概率解释的场景

### 13.8.4 核K-Means：处理非线性数据

**问题**：K-Means只能找到球形簇。如果数据是环形、S形怎么办？

**解决方案**：把数据映射到高维空间，在那里做K-Means。

**核心思想**：
- 原始空间：点$x$和$y$距离$\|x-y\|^2$
- 特征空间：$\|\phi(x) - \phi(y)\|^2$，其中$\phi$是非线性映射
- 用核技巧避免显式计算$\phi$

**常用核函数**：RBF核 $K(x, y) = \exp(-\gamma \|x - y\|^2)$

**适用**：复杂形状、非线性分布的数据

### 13.8.5 谱聚类：基于图论的聚类

**核心思想**：把聚类问题转化为图切割问题。

**步骤**：
1. 构建相似度图（每个点是节点，相似度是边权重）
2. 计算图的拉普拉斯矩阵
3. 对拉普拉斯矩阵特征分解
4. 用前K个特征向量作为新特征
5. 在新特征空间做K-Means

**优点**：能处理任意形状的簇
**缺点**：计算复杂度高（$O(n^3)$）

### 13.8.6 深度聚类：神经网络+K-Means

**核心思想**：先用神经网络学习好的特征表示，再做K-Means。

**代表方法**：
- **DEC**（Deep Embedded Clustering）：联合优化特征和聚类
- **IDEC**：改进版，保留数据结构
- **自编码器+K-Means**：先用自编码器降维，再聚类

**突破**：深度聚类在图像聚类上取得了惊人效果，甚至超过了有监督方法！

## 13.9 从K-Means到深度学习：聚类的进化之路

### 13.9.1 矢量量化与表示学习

K-Means本质上是一种**矢量量化**（Vector Quantization, VQ）技术：用K个码本向量表示所有数据。

这个思想直接启发了深度学习中的重要组件：
- **VQ-VAE**：向量量化变分自编码器，用于生成高清图像
- **码本学习**：自监督学习中的离散表示

### 13.9.2 K-Means与EM算法的联系

K-Means是EM算法的"硬分配"版本：
- K-Means：每个点属于一个簇（概率为1或0）
- GMM（高斯混合模型）：每个点以概率属于多个簇

**联系**：
- K-Means ≈ GMM的极限情况（方差→0）
- EM算法 = 软版本的K-Means

### 13.9.3 聚类与降维的协同

高维数据上做K-Means效果差（维度灾难）。解决方案：
1. 先用PCA/t-SNE降维
2. 在低维空间做K-Means

这就像：先给数据"拍张X光片"（降维），再"分类整理"（聚类）。

### 13.9.4 聚类与半监督学习

当只有少量标签、大量无标签数据时：
1. 用K-Means聚类
2. 给每个簇分配标签（根据簇内有标签的样本投票）
3. 用这些"伪标签"训练分类器

这种方法在医学影像分析中特别有用——标注数据昂贵，但无标签数据 plentiful。

### 13.9.5 前沿：可微分K-Means

传统K-Means不可导，无法端到端训练。**最新研究**试图解决这个问题：
- 用软分配代替硬分配
- 用Sinkhorn算法近似最优传输
- 将K-Means作为神经网络的一个层

这标志着聚类算法从"独立工具"向"深度学习组件"的进化。

## 13.10 实战演练：图像颜色量化完整项目

### 13.10.1 项目目标

用K-Means把任意照片压缩成指定颜色数，同时保持视觉效果。

### 13.10.2 完整代码

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import KMeans
from PIL import Image

def color_quantization(image_path, n_colors=16, show_result=True):
    """
    用K-Means实现图像颜色量化
    
    参数：
        image_path: 图片路径
        n_colors: 量化后的颜色数
        show_result: 是否显示结果
    """
    # 1. 加载图像
    img = Image.open(image_path)
    img_array = np.array(img)
    
    # 记录原始尺寸
    original_shape = img_array.shape
    
    # 2. 重塑数据：把像素变成样本点 (h*w, 3)
    pixels = img_array.reshape(-1, 3)
    
    # 3. 运行K-Means
    print(f"正在用K-Means聚类成{n_colors}个颜色...")
    kmeans = KMeans(n_clusters=n_colors, random_state=42, n_init=10)
    kmeans.fit(pixels)
    
    # 4. 用聚类中心替换原始颜色
    quantized_pixels = kmeans.cluster_centers_[kmeans.labels_]
    
    # 5. 重塑回图像形状
    quantized_img = quantized_pixels.reshape(original_shape).astype(np.uint8)
    
    # 6. 计算压缩效果
    original_size = original_shape[0] * original_shape[1] * 24  # 24位色
    compressed_size = n_colors * 24 + original_shape[0] * original_shape[1] * np.log2(n_colors)
    compression_ratio = (1 - compressed_size / original_size) * 100
    
    print(f"原始大小: {original_size/8/1024:.1f} KB")
    print(f"压缩后大小: {compressed_size/8/1024:.1f} KB")
    print(f"压缩率: {compression_ratio:.1f}%")
    
    # 7. 可视化
    if show_result:
        fig, axes = plt.subplots(1, 3, figsize=(15, 5))
        
        # 原始图
        axes[0].imshow(img_array)
        axes[0].set_title(f'原始图像\n{original_shape[0]}x{original_shape[1]}')
        axes[0].axis('off')
        
        # 量化图
        axes[1].imshow(quantized_img)
        axes[1].set_title(f'K-Means量化\n{n_colors}种颜色')
        axes[1].axis('off')
        
        # 调色板
        palette = kmeans.cluster_centers_.astype(np.uint8).reshape(1, -1, 3)
        axes[2].imshow(palette)
        axes[2].set_title(f'提取的{n_colors}色调色板')
        axes[2].axis('off')
        
        plt.tight_layout()
        plt.savefig('color_quantization_result.png', dpi=150, bbox_inches='tight')
        plt.show()
    
    return quantized_img, kmeans

# 运行示例
```

```python
def find_optimal_colors(image_path, max_colors=32):
    """用肘部法则找到最佳颜色数"""
    img = Image.open(image_path)
    pixels = np.array(img).reshape(-1, 3)

    if len(pixels) > 10000:

        kmeans = KMeans(n_clusters=k, random_state=42, n_init=5)

        print(f"K={k}, 惯性={kmeans.inertia_:.2e}")
    
    # 绘图

    plt.title('肘部法则：选择最佳颜色数')
    plt.grid(True)

    return inertias
```

## 13.12 常见误区与避坑指南

即使是经验丰富的数据科学家，也会在使用K-Means时犯错。这里总结了最常见的陷阱。

### 误区1：忘记标准化数据

**错误场景**：
你有一个客户数据集，包含"年龄"（0-100）和"年收入"（0-1000000）。如果不标准化，年收入会完全主导距离计算——因为1000000远大于100。

**后果**：
聚类结果实际上只反映了"收入"这一个维度，年龄被忽略了。

**正确做法**：
```python
from sklearn.preprocessing import StandardScaler
X_scaled = StandardScaler().fit_transform(X)
kmeans.fit(X_scaled)
```

### 误区2：忽视高维诅咒

**错误场景**：
直接在1000维的基因数据上做K-Means。

**后果**：
高维空间中，所有点之间的距离都差不多（距离集中现象），K-Means失效。

**正确做法**：
先降维到10-50维（PCA），再聚类。

### 误区3：K值随意选

**错误场景**：
"我觉得分成5类不错"，没有任何数据支持。

**后果**：
可能错过真正的数据结构，或过度分割。

**正确做法**：
肘部法则 + 轮廓系数 + 稳定性分析 + 业务验证，四管齐下。

### 误区4：只看聚类标签，不看簇特征

**错误场景**：
运行完K-Means，只看"样本A属于簇2"，但不关心"簇2有什么特征"。

**后果**：
聚类变成了无意义的数字游戏，无法指导业务决策。

**正确做法**：
对每个簇，分析：
- 簇中心是什么？
- 簇内样本的统计特征？
- 与其他簇的区别？
- 业务上代表什么群体？

### 误区5：在任意形状数据上硬用K-Means

**错误场景**：
数据明显是环形分布，但强行用K-Means分成3类。

**后果**：
K-Means会把环形切成几块，而不是识别出"一个环"。

**正确做法**：
先可视化数据（散点图），判断簇的形状。如果是非球形，用DBSCAN或谱聚类。

### 误区6：忽视空簇问题

**错误场景**：
设置K=10，但某个簇没有样本。

**后果**：
sklearn会发出警告，某些实现会报错。

**正确做法**：
- 检查K是否太大
- 对空簇重新初始化或删除
- 考虑是否适合用K-Means

### 误区7：不做稳定性检验

**错误场景**：
运行一次K-Means，结果看起来不错，直接采用。

**后果**：
K-Means对初始值敏感，一次运行可能只是"运气"。

**正确做法**：
- 多次运行（不同的random_state）
- 比较聚类结果的相似性（Adjusted Rand Index）
- 如果结果不稳定，增加n_init或换算法

### 误区8：把聚类当作分类

**错误场景**：
用聚类结果直接作为"类别标签"去训练分类器，不做任何验证。

**后果**：
聚类标签可能没有实际意义，分类器学到的是伪模式。

**正确做法**：
- 先解释聚类的业务含义
- 用有标签数据验证聚类质量
- 必要时请领域专家审核

### 避坑总结

```
使用K-Means前的自检清单：

□ 数据已标准化？
□ 已处理缺失值和异常值？
□ 维度不高（或已降维）？
□ 簇大致是球形？
□ K值有数据支持？
□ 已可视化检查？
□ 多次运行验证稳定性？
□ 聚类结果有业务解释？
□ 不是把聚类当分类用？
```

## 13.14 深度案例：Netflix的电影推荐系统

### 背景

Netflix是全球最大的流媒体平台之一，拥有超过2亿用户和数万部电影。一个核心问题是：**如何向每个用户推荐他们可能喜欢的电影？**

K-Means在这里扮演了一个重要角色——不是直接推荐电影，而是**发现用户的"观影品味群体"**。

### 数据准备

Netflix收集了大量用户行为数据：
- **评分数据**：用户对电影的1-5星评分
- **观看行为**：看了多久、是否看完、重看次数
- **元数据**：喜欢的类型、演员、导演、年代

每个用户被表示为一个高维向量：
```

```

维度可能高达100+。

### 聚类过程

**第一步：降维**
先用PCA把100维降到10维。为什么？因为用户的"真实品味"可能只有几个核心维度：
- 维度1："爆米花指数"（喜欢轻松娱乐 vs 严肃深刻）
- 维度2："探索指数"（喜欢新片 vs 经典片）
- 维度3："社交指数"（独自看 vs 陪家人看）
...

**第二步：K-Means聚类**
用K-Means++把用户分成50个"品味群体"。

**第三步：群体画像**
分析每个群体的特征：

| 群体 | 昵称 | 特征 | 推荐策略 |
|:---|:---|:---|:---|
| 群体1 | "爆米花族" | 爱看动作、喜剧，周末晚上看 | 推荐最新大片、热门喜剧 |
| 群体2 | "文艺青年" | 偏爱独立电影、外国片 | 推荐戛纳获奖片、艺术电影 |
| 群体3 | "怀旧派" | 只看80-90年代经典 | 推荐经典修复版、导演回顾 |
| 群体4 | "追剧狂魔" | 只看剧集，一口气追完 | 推荐新剧全集、相似剧集 |
| 群体5 | "家庭观影" | 儿童片+合家欢，晚上看 | 推荐迪士尼、皮克斯、家庭喜剧 |

### 推荐算法

当需要给用户推荐时：
1. 确定用户属于哪个群体
2. 看该群体中其他用户喜欢什么电影
3. 排除用户已经看过的
4. 综合评分、热度、多样性，生成推荐列表

### 效果

Netflix估计，其推荐系统每年为平台节省**10亿美元**（减少了用户流失）。75%的观看内容来自推荐，而非用户主动搜索。

### 本章小结

K-Means是机器学习中最经典的聚类算法，它的核心思想简单却深刻：

- **物以类聚**：相似的点应该在一起
- **中心代表**：用平均值代表一个群体
- **迭代优化**：分配-更新循环直到收敛

关键概念：
- **Lloyd算法**：标准的K-Means实现

## 附录A：K-Means数学推导

### A.1 目标函数推导

K-Means的目标是最小化WCSS（Within-Cluster Sum of Squares）：

$$J = \\sum_{i=1}^{k} \\sum_{x \\in C_i} \\|x - \\mu_i\\|^2$$

其中：
- $k$ 是聚类数
- $C_i$ 是第$i$个簇的样本集合
- $\\mu_i$ 是第$i$个簇的中心
- $\\|x - \\mu_i\\|^2$ 是样本$x$到中心$\\mu_i$的欧氏距离平方

### A.2 算法收敛性证明

**定理**：K-Means算法必然收敛到局部最优。

**证明**：

1. **E步骤（分配）**：固定中心$\\mu_i$，将每个样本分配到最近的中心
   - 这一步使$J$减小或保持不变

2. **M步骤（更新）**：固定分配，更新中心为簇内样本均值
   $$\\mu_i = \\frac{1}{|C_i|} \\sum_{x \\in C_i} x$$
   
   由均值的最优性，这一步也使$J$减小或保持不变

3. **收敛性**：由于$J \\geq 0$且每次迭代$J$不增，算法必然收敛。

**注意**：收敛到的是局部最优，不是全局最优。

### A.3 时间复杂度分析

- **每次迭代**：$O(n \\cdot k \\cdot d)$
  - $n$：样本数
  - $k$：聚类数  
  - $d$：特征维度

- **总复杂度**：$O(t \\cdot n \\cdot k \\cdot d)$
  - $t$：迭代次数（通常$\\lt 100$）

### A.4 空间复杂度

- **存储样本**：$O(n \\cdot d)$
- **存储中心**：$O(k \\cdot d)$
- **存储标签**：$O(n)$
- **总计**：$O(n \\cdot d + k \\cdot d)$

## 附录B：K-Means算法伪代码

### B.1 标准K-Means

```
算法：K-Means
输入：数据集X，聚类数k，最大迭代次数max_iter
输出：簇标签labels，簇中心centroids

1. 随机初始化k个中心点：centroids = RandomSample(X, k)
2. for iter = 1 to max_iter:
3.     # E步骤：分配样本到最近中心
4.     for each x in X:
5.         labels[x] = argmin_i ||x - centroids[i]||
6.     
7.     # 保存旧中心
8.     old_centroids = centroids
9.     
10.    # M步骤：更新中心
11.    for i = 1 to k:
12.        centroids[i] = mean(X[labels == i])
13.    
14.    # 检查收敛
15.    if ||centroids - old_centroids|| \\lt epsilon:
16.        break
17. 
18. return labels, centroids
```

### B.2 K-Means++初始化

```
算法：K-Means++
输入：数据集X，聚类数k
输出：初始中心点centroids

1. centroids[0] = RandomSample(X, 1)  # 随机选第一个中心
2. for i = 1 to k-1:
3.     # 计算每个样本到最近中心的距离
4.     for each x in X:
5.         D[x] = min_j ||x - centroids[j]||^2
6.     
7.     # 按概率选择下一个中心
8.     # P(x) = D[x] / sum(D)
9.     centroids[i] = Sample(X, weights=D)
10. 
11. return centroids
```

## 附录C：Python实现细节

### C.1 向量化计算

```python
import numpy as np

def kmeans_vectorized(X, k, max_iter=100):
    n_samples, n_features = X.shape
    
    # 随机初始化
    centroids = X[np.random.choice(n_samples, k, replace=False)]
    
    for _ in range(max_iter):
        # 计算所有样本到所有中心的距离（向量化）
        distances = np.sqrt(((X[:, np.newaxis] - centroids) ** 2).sum(axis=2))
        
        # 分配标签
        labels = np.argmin(distances, axis=1)
        
        # 更新中心
        new_centroids = np.array([X[labels == i].mean(axis=0) for i in range(k)])
        
        # 检查收敛
        if np.allclose(centroids, new_centroids):
            break
        
        centroids = new_centroids
    
    return labels, centroids
```

### C.2 距离计算优化

```python
# 计算距离的平方，避免sqrt
squared_distances = ((X[:, np.newaxis] - centroids) ** 2).sum(axis=2)
```

### C.3 Mini-Batch K-Means

```python
def minibatch_kmeans(X, k, batch_size=100, max_iter=100):
    n_samples = X.shape[0]
    centroids = X[np.random.choice(n_samples, k, replace=False)]
    counts = np.zeros(k)
    
    for _ in range(max_iter):
        batch_idx = np.random.choice(n_samples, batch_size)
        batch = X[batch_idx]
        
        distances = ((batch[:, np.newaxis] - centroids) ** 2).sum(axis=2)
        labels = np.argmin(distances, axis=1)
        
        for i in range(k):
            mask = (labels == i)
            if mask.any():
                counts[i] += mask.sum()
                centroids[i] = ((counts[i] - mask.sum()) * centroids[i] + 
                               batch[mask].sum(axis=0)) / counts[i]
    
    return centroids
```

## 附录F：实战案例——客户分群

### F.1 问题描述

某电商公司想对客户进行分群，制定精准营销策略。

### F.2 数据准备

- 特征：年龄、年收入、消费频次、平均订单金额
- 样本：10,000名客户

### F.3 分析步骤

```python
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

# 加载数据
data = pd.read_csv('customers.csv')
X = data[['age', 'income', 'frequency', 'avg_order']]

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 确定k值
from sklearn.metrics import silhouette_score

scores = []
for k in range(2, 10):
    kmeans = KMeans(n_clusters=k, random_state=42)
    labels = kmeans.fit_predict(X_scaled)
    score = silhouette_score(X_scaled, labels)
    scores.append((k, score))
    print(f"k={k}, 轮廓系数={score:.3f}")

# 选择最佳k
best_k = max(scores, key=lambda x: x[1])[0]
print(f"最佳聚类数: {best_k}")

# 最终聚类
kmeans = KMeans(n_clusters=best_k, random_state=42)
data['cluster'] = kmeans.fit_predict(X_scaled)

# 分析每个簇的特征
for i in range(best_k):
    cluster_data = data[data['cluster'] == i]
    print(f"\\n簇 {i}:")
    print(f"  人数: {len(cluster_data)}")
    print(f"  平均年龄: {cluster_data['age'].mean():.1f}")
    print(f"  平均收入: {cluster_data['income'].mean():.0f}")
    print(f"  平均消费频次: {cluster_data['frequency'].mean():.1f}")
```

### F.4 结果解释

假设分成4类：

| 簇 | 昵称 | 特征 | 营销策略 |
|:---|:---|:---|:---|
| 0 | 高价值客户 | 高收入、高频次 | VIP专属服务 |
| 1 | 潜力客户 | 高收入、低频次 | 提升活跃度 |
| 2 | 忠实客户 | 低收入、高频次 | 保持粘性 |
| 3 | 流失风险 | 低活跃 | 召回活动 |

## 附录I：费曼学习法——用简单语言解释K-Means

### I.1 给小学生讲K-Means

**比喻**：整理杂乱的玩具

想象你的房间里有100个玩具，乱七八糟地散落在地上。妈妈让你把它们分类放好。

K-Means就像这样：
1. 你先随便选几个地方作为"整理中心"（初始化）
2. 把每个玩具放到最近的整理中心（分配）
3. 重新计算每个整理中心的"中间位置"（更新）
4. 重复2-3步，直到整理中心不再移动（收敛）

最后，你可能会发现：
- 一堆是积木类
- 一堆是汽车类  
- 一堆是娃娃类
- 一堆是球类

这就是K-Means！它自动帮你把相似的东西放在一起。

### I.2 给中学生讲K-Means

**比喻**：组织课外兴趣小组

学校有1000名学生，你想把他们分成5个兴趣小组。

每个学生有一个"兴趣向量"：
- 对数学的兴趣（0-10分）
- 对物理的兴趣（0-10分）
- 对文学的兴趣（0-10分）
- 对艺术的兴趣（0-10分）

**K-Means过程**：
1. 随机选5个学生作为小组长（初始中心）
2. 每个学生加入兴趣最接近的小组
3. 重新计算每个小组的"平均兴趣"（新中心）
4. 重复直到小组稳定

**为什么有效**？
因为兴趣相似的人会自然聚集在一起，就像现实中志同道合的朋友。

### I.3 给大学生讲K-Means

**比喻**：数据压缩与表示学习

K-Means本质上是一种**矢量量化**（Vector Quantization）技术。

**信息论视角**：
- 用k个中心点近似n个数据点
- 压缩率：$\\frac{n \\cdot d}{k \\cdot d + n \\cdot \\log_2 k}$
- 失真：量化误差（WCSS）

**优化视角**：
K-Means求解的是：
$$\\min_{\\mu, C} \\sum_{i=1}^{k} \\sum_{x \\in C_i} \\|x - \\mu_i\\|^2$$

这是一个NP难问题，Lloyd算法提供了一个有效的近似解。

### I.4 给研究者讲K-Means

**概率视角**：

K-Means可以看作是高斯混合模型（GMM）的硬分配版本：

- GMM：$P(x) = \\sum_{i=1}^{k} \\pi_i \\mathcal{N}(x | \\mu_i, \\Sigma_i)$
- K-Means：假设$\\Sigma_i = \\sigma^2 I$且$\\sigma \\to 0$

**变分推断视角**：

K-Means等价于对GMM进行EM算法，但使用硬分配（hard assignment）而非软分配（soft assignment）。

**核方法视角**：

通过核技巧，K-Means可以在高维特征空间进行聚类：
$$\\phi(x) \\to \\text{K-Means in feature space}$$

### J.2 为什么是"K"？

"K"来源于统计学中的传统记号：

### J.3 Lloyd是谁？

Stuart P. Lloyd (1923-2007)，贝尔实验室数学家。

他的K-Means算法最初用于**脉冲编码调制**（PCM）的信号量化，后来被发现是最通用的聚类算法之一。

论文直到1982年才正式发表，之前以贝尔实验室技术报告形式流传了25年。

### J.4 K-Means++的突破

2007年，David Arthur和Sergei Vassilvitskii证明：

通过 careful seeding（K-Means++初始化），可以得到$O(\\log k)$近似比的解。

这意味着：好的初始化可以理论保证找到不错的解！
